# L4 → L5 Promo Doc — Synthesized Template

Merged skeleton extracted from the two peer L4→L5 docs Matt shared (Shelby King, Niko
Tellez). Each section notes which parent it comes from, its purpose, and the structural
rules to follow. Fill the `‹slots›`. Voice/framing principles live in `tracker.md`
(cloud-to-dirt, apples-to-apples, outcomes-over-tools).

**Structural DNA both docs share (the non-negotiables):**
1. Every example is ONE dense paragraph — mechanism + a **bold headline number stated early** + the cross-functional partners + LP tags.
2. Examples lead with an **authorship verb** ("Nik led the design and documentation…", "Shelby built…"). Ownership by-authorship, not by-assignment.
3. 4 examples is the observed count (Shelby 4, Niko 4). 5 is the ceiling — don't pad.
4. The Scope/opener carries the **sizing sentence** (sites + units/wk) and the **org-level $ goal** the role optimizes for.
5. No inline manager-praise quotes, no methodology sub-details, no attestation callouts in the body — those live in a separate feedback section or not at all.

## 1. Career-arc opener  *(Shelby pattern; Niko folds this into the intro)*

**Purpose:** one paragraph — join date/level → progression → **what you own today**, ending on the sizing sentence.
**Rules:** past-tense arc, then a bold present-tense "Today, ‹name› owns ‹scope›" sentence with the **sizing number**. Shelby: "26 buildings, 5.03% of network MDP, ~100K ISAs annually." Keep it to the scope you actually own.

```
‹Name› joined Amazon in ‹month year› as a ‹entry level/title› ‹where›. Over ‹span›,
‹name› ‹progression›. In ‹current role›, ‹name› quickly demonstrated capabilities beyond
L4 expectations — ‹1-line pattern: root-cause / challenge seniors with data / build
scalable mechanisms›. **Today, ‹name› owns ‹scope in one clause› — ‹SIZING: N sites and
~X units/week›.** ‹name› also ‹1-2 adjacent programmatic ownerships›.

The following examples demonstrate ‹L5 pattern in one sentence — ambiguous problems w/
limited guidance, codified mechanisms over hand-offs, cross-org consensus›.
```

## 2. Scope of Role  *(Niko standalone section; optional if #1 already carries scope)*

**Purpose:** define the SCMII role as an ambiguous, un-codified IC space; prove you operate 3 levels up; include an **illustrative pushback vignette**; restate sizing; name the org $ goal.
**Rules:** one dense paragraph. Niko's shape: role definition → "for example, ‹site› ‹missed X›, rather than blanket-approve the SCMII flags the incongruency and pushes upstream" → **sizing sentence** → "brings clarity to a largely ambiguous space via ‹auditing guardrails / delegating to tooling›" → org goal (Niko: "-$4M / -95% YoY AR-S NTI spend") → holds internal/external partners to the same bar → **Quality / Speed / Tact** communication close.

```
As a Supply Chain Manager II within ‹org›, the ‹role name› role is an individual
contributor scope where ‹the rules for the work aren't codified — tribal knowledge›.
Exceptional understanding of ‹domain: MDP / buffer / G2G / yard› is required to guide
‹tactical stakeholders›, lead escalations up to three levels above their own, and push
back with data on ‹asks that shift rather than solve the problem›. For example, ‹pushback
vignette›. **The SCMII owns ‹SIZING sentence›.** ‹builds tooling/standards that surface the
right callouts and codify the rules›. ‹optimizes for org goal: $ / units / %›. It holds
internal & external partners (‹names of teams, not people›) to the same data bar, and
autonomously flags when a plan is risky. Finally, it requires high-**Quality**,
high-**Speed**, high-**Tact** written & verbal communication — demonstrated in business
reviews and director-level escalations.
```

## 3. Promotion Assessment — Introduction  *(both)*

**Purpose:** bold thesis sentence ("‹Name› is the ‹anchor/center› of ‹workstream›") → the consolidation story (what distributed scope you absorbed into one L4 role) → 2-3 headline outcomes across H1 → an Earn-Trust closer (relationships enable the cross-org wins).

historically required X›. **‹Consolidation sentence: what you absorbed from an L5 / multiple
leaders into one L4-owned mechanism›.** Across H1 2026, ‹he/she› ‹outcome 1 w/ number›,
‹outcome 2 w/ number›, and ‹outcome 3 w/ number›. Not to be dismissed is ‹name›'s ability

A WorkDocs link to artifacts referenced in the following examples is provided here: ‹URL›.

## 4. Evidence — Examples  *(both; 4 examples, 5 max)*

**Purpose:** each proves one L5 behavior with a mechanism and a number.
**Per-example rules:**
- **Bold title** naming the deliverable (Niko appends "(Artifact #N)" + implies a WorkDocs artifact; Shelby uses "Example N: ‹Title›"). Pick one convention and hold it.
- **Lead with the bold headline number** in sentence 1 or 2 (Shelby: "freed 39,875 placeholder ISAs"; Niko: "-101M Units / -75%").
- One dense paragraph: problem → what wasn't codified/owned → **what YOU authored/built/led** → the number → cross-functional partners aligned.
- Close each with **[LP tags]** and a *Role guideline: ‹the SCM guideline line this maps to›* (Shelby maps every example to a role guideline — do this).
- Spread the LPs across examples so the set covers Ownership, Deliver Results, Invent & Simplify, Earn Trust, Dive Deep, Have Backbone.

```
**Example ‹N›: ‹Deliverable title›**
**‹Bold headline number + outcome›** — ‹1-line context of the win›. ‹Problem state: what
was broken / ambiguous / un-owned›. **‹What YOU authored/built/led — authorship verb›.**
‹Mechanism detail + how it works›. ‹Cross-functional partners aligned + timeframe›. ‹Result
/ what it unlocks›.
**Leadership Principle(s) demonstrated:** ‹3-4 LPs›
*Role guideline: ‹the "Moving to L5" SCM guideline line this example evidences›.*
```

## 5. Summary  *(optional; both use it for the people-leadership shape)*

**Purpose:** the early shape of L5 people-leadership. Niko = concrete mentorship of an L3 with tangible results. Shelby folds forward-scope here.
**Rules:** if you have real mentorship/enablement, state it concretely (who, what they can now do independently). If not, use the "codified judgment → transferable team tooling" framing — but keep it honest (don't claim direct reports you don't have).

```
Beyond these core deliverables, ‹name› ‹people-leadership / enablement shape — mentorship
OR turning personal capability into team tooling others run without you›. ‹Tangible result›.
This positions ‹name› to ‹partner with / develop AA-level talent› as the scope formalizes.
```
