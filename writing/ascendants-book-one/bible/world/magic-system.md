# Magic System

*The load-bearing world file for most fantasy. Claude will **not** invent answers here — if a rule isn't written down, it should ask you. That's deliberate: it keeps your world yours and stops the bible getting polluted with decisions you never made.*

## Hard or soft?

*(Sanderson's framing: **hard** = readers understand the rules and can predict what's possible → magic can solve problems satisfyingly. **soft** = mysterious and awe-driven → magic should mostly cause problems, not solve them. Neither is better; picking one prevents a lot of later pain.)*

## Rules

- **Who can use it / how is that determined?** *(bloodline, training, chosen, anyone)*
- **What does it let you do?**
- **What can it absolutely NOT do?** *(the most important question — limits create tension)*

## Cost

*(Magic without cost drains stakes. What does using it take — physical toll, moral compromise, finite resource, time, sanity, something borrowed from someone else?)*
